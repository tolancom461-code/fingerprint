## نطاق الفحص والدليل

نفذ حساب الفحص 48 استعلام SELECT وSHOW على المصدر، بمهل محدودة واتصال TLS موثق الشهادة وهوية المضيف. لم تستخدم SET أو START TRANSACTION أو LOCK أو FLUSH أو أوامر إنشاء/تعديل/حذف، ولا تجربة كتابة مرفوضة. المقارنة مع الوجهة كانت قراءة فقط أيضًا.

الفحص اقتصر على metadata لجداول البصمة العشرة، وتعريفاتها وفهارسها، والأعداد وحدود المفاتيح والتوقيت وتعداد الحالات وفحوص العلاقات. لم يقرأ صفوف أسماء أو أكواد أشخاص أو أرقام أجهزة أو payload أو notes أو بيانات اليومية والرواتب. حفظت بيانات الاعتماد في `.env.tidb-source` المحلي المستبعد، ولم تضمّن في سجل SQL أو النتائج.

الأدلة في `verification/source-tidb-readonly-probe-2026-11-09.json` و`verification/source-database-inspection-2026-11-09.json` و`verification/source-database-schema-reference-2026-11-09.json`. الأخير مرجع تعريفات مصدر ووجهة فقط، ولا يمثل نسخة بيانات أو ملفًا معتمدًا للتنفيذ.

## ما يجب الحفاظ عليه عند النسخ

- لا يقتصر النقل على الأحداث النهائية الـ33. تحفظ سجلات الاستقبال والبصمات والمعالجة والروابط والمسائل والتدقيق مع المفاتيح والإصدارات وحالاتها.
- توجد 206 مسائل مفتوحة لمستخدمي أجهزة غير مربوطين، و4 بصمات بلا توقيت UTC. تنقل كما هي وتراجع منفصلة؛ لا يعالجها النقل تلقائيًا أو يحذفها.
- توجد 244 حالة معالجة processed وحالة not_applicable واحدة. اختلاف عدادات المراحل لا يثبت فقدًا وحده.
- النطاق المحلي للبصمات من 30 أغسطس إلى 4 أكتوبر 2026؛ لا يدل ذلك على استخراج كل التاريخ الموجود على الجهاز. يحتوي المصدر أيضًا إصدار حدث نهائي من إعادة معالجة تاريخية، وتحفظ هويته دون إعادة إصدار.
- جداول العمال واليومية والرواتب وربط الأشخاص بالعامل وسجل استيراد TolanHR ومؤشره تبقى لدى التطبيق الرئيسي. مؤشر Web Bridge الملفي مطلب حفظ منفصل، ولا يصفّر عند التحويل.
