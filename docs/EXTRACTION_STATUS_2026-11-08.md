# سجل استخراج مصدر نظام البصمة المستقل

التاريخ: 8 نوفمبر 2026. المصدر: `finger/biometric-service`. الهدف: `biometric-system` كمشروع مستقل بجوار `finger` داخل مساحة العمل.

## قبل التعديل

مصدر الخدمة داخل مشروع TolanHR، بالإصدار `0.18.0` وباختبارات وتشغيل مستقلين أصلًا. خدمة Windows المثبتة تعمل من `C:\Tolan\BiometricService`، وهو مسار مختلف عن المصدر. لم يكن مجلد الهدف موجودًا.

الخطوة المعتمدة هي إنشاء نسخة مصدر وتوزيع مستقلة، مع إبقاء المصدر والتشغيل الحاليين دون تغيير. لا تشمل هذه الخطوة تحويل الجهاز أو ترحيل القاعدة أو نشر الخدمة أو إتاحة الإدارة للعامة.

## ما تغير

- نسخت المجلدات `src/` و`tests/` و`docs/` و`database/`، وملفات `package.json` و`package-lock.json` و`.env.example`.
- سجلت 176 ملفًا منقولًا مع بصمات SHA-256 في `SOURCE_SNAPSHOT_MANIFEST.json`.
- بقيت ملفات المصدر التنفيذي والاختبارات وملفات الحزم المنقولة مطابقة للمصدر الأصلي؛ لا توجد تعديلات سلوك في هذه الخطوة.
- أضيف README مخصص للاستقلال، وملفات تجاهل لحماية الأسرار والبيانات المحلية من المستودع وحزم التوزيع.
- حفظ README السابق كوثيقة تاريخية مع بيان مصدره وحدود مساراته القديمة.

لم تنسخ `.env` أو `var/` أو مؤشرات Web Bridge أو سجلات الأجهزة أو `node_modules` أو ملفات exe/xml الخاصة بخدمة Windows أو ملفي `cd` و`node` غير المناسبين للتوزيع. تثبت الاعتماديات من lockfile بصورة مستقلة.

## نتائج التحقق

- تثبيت مستقل بـ`npm ci --offline --ignore-scripts --no-audit --no-fund`: نجح من cache محلي، وثبت 12 حزمة من lockfile دون تشغيل install scripts أو استخدام الشبكة. احتاجت قراءة cache صلاحية خارج قيود العزل بعد محاولة أولى فشلت بـ`EPERM`.
- `npm test`: نجح 194 اختبارًا من 194، دون فشل أو تخطٍ.
- `npm run check:boundaries`: نجحت الاختبارات الستة، وهي مجموعة فرعية من الاختبارات السابقة وليست ستة اختبارات إضافية.
- مقارنة SHA-256: الملفات المنقولة الـ176 مطابقة لبصمات الأصل، والمصدر الأصلي ما زال مطابقًا للبصمات نفسها. ملفات `src/` و`tests/` لم تتغير.
- `npm pack --dry-run --json --ignore-scripts`: نجح؛ حزمة التوزيع المتوقعة تشمل 180 ملفًا ولا تشمل `.env` أو بيانات `var/` أو سجلات أو مؤشرات أو `node_modules` أو أدلة التحقق. `.env.example` العام مشمول.
- لا يوجد ملف `.env` أو مجلد بيانات `var/` أو wrapper خدمة Windows داخل النسخة المستقلة. لم تحول خدمة الإنتاج إلى هذا المشروع.
- بعد الاستخراج نفذ فحص تشغيل معزول للتأكد من تحميل الحزمة واعتمادياتها: استماع على `127.0.0.1` ومنفذ مؤقت، وتخزين ملفي تحت مجلد الأدلة المحلي خارج المشروع، مع تعطيل الإدارة وAPI والإرسال وقبول الأجهزة. أعاد `/health` القيمة `OK` وأوقفت العملية بعد الفحص، دون استخدام قاعدة الإنتاج أو الجهاز أو منفذ `9095`.
- تحقق المراجع من حل `mysql2` من `node_modules` الخاص بالمشروع المستقل، ومن بقاء 109 ملفات أصلية لخدمة البصمة و454 ملفًا من التطبيق الرئيسي دون تغيير.

بيئة التحقق: Node.js `v24.15.0` وnpm `11.12.1`. تحفظ السجلات المحلية تحت `verification/`، وهو مستبعد من git وDocker وحزمة npm.

## ما بقي

إغلاق التحضير يتطلب نسخ البيانات القابلة للاستعادة وحصر التاريخ واستخراجه من الجهاز بصورة مثبتة. بقية المرحلة الأولى تشمل الإدارة المستقلة والوصول الآمن والنشر المجرب؛ فصل المجلد وحده لا يكملها. فصل القاعدة وإعادة ربط TolanHR والبرامج الأخرى لم يبدأا ضمن هذا الاستخراج.

## التراجع

المصدر والتشغيل والقاعدة والجهاز لم تحول إلى المجلد الجديد؛ لذلك يمكن عدم استخدام هذه النسخة دون تغيير تشغيل الإنتاج. لا تحذف النسخة الأصلية أو السجلات، ولا تعيد إصدار الأحداث بهويات جديدة بغرض نقلها.
